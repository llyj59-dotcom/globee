선생님(교사)용 웹앱입니다. 로그인 없이 누구나 열어 볼 수 있고, 내용 업데이트는 선생님이 `index.html`을 고쳐서 합니다.
색은 Jincerely 블로그 색(크림 · 짙은 청록 · 연한 민트)을 씁니다.

## 내용 고치기

`index.html`을 열면 `<script>` 바로 아래에 **"★ 선생님이 고치는 곳"** 표시가 있고, 거기서부터 **"데이터 끝"**까지가 전부 데이터입니다.

- `APP_NAME`, `APP_SUB`: 이름과 부제
- `STEPS`: 순서 단계와 체크 항목. `go:'docs:consent'`처럼 적으면 바로가기 단추가 붙음
- `DOCS`: 서류 틀. `tpl`이 복사되는 본문, `link`에 드라이브 완성본 주소
- `SITES`: 사이트 모음. `n`은 주의 문구
- `STD`: 성취기준 `'코드':'문장'`. 2022 개정은 별책2 원문과 대조했고, 인천형은 교육청 해설서 문구
- `FW`: 추천에 쓰는 틀(인천형 `ic`, 유네스코 `gced`, IB `ib`, SDG, 교과)
- `PROJECTS`: 추천 프로젝트. `band`·`ic`·`ib`·`gced`·`sdg`·`subj`·`mode`·`len`으로 추천 점수를 매김
- `PARTNER`, `COUNTRIES`: 파트너교 질문과 나라 정보 `[이름, 시차, 수도, 언어, 화폐, 인사말, 비고]`
- `MAIL_KINDS`, `PHRASES`: 메일 틀과 표현. `{name}` 같은 자리는 입력칸에서 채워짐
- `SYN`: "내 주제로 엮기"의 낱말 연결표. 주제에 왼쪽 낱말이 있으면 오른쪽 낱말들로도 성취기준을 찾음
- `FAQ`: 처음 화면의 "처음 궁금한 것" 질문·답

따옴표(`'`)와 쉼표만 지키면 됩니다. 문장 안에 `'`가 필요하면 `\'`로 씁니다.

## 저장되는 것

체크·입력은 그 기기 브라우저(`localStorage`, 키 `globee-v1`)에만 저장됩니다. 외부로 보내는 것은 없습니다.
**아이들 이름·사진은 앱에 넣지 않습니다.** 공개 주소이기 때문입니다.
